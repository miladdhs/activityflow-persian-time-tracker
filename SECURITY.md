# Security Policy

## Supported versions

Security fixes are released for the latest version only. Please always use the
[latest release](https://github.com/miladdhs/activityflow-persian-time-tracker/releases/latest).

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Instead, report them privately through
[GitHub Security Advisories](https://github.com/miladdhs/activityflow-persian-time-tracker/security/advisories/new).

Include a description of the issue, steps to reproduce and the affected version. You will receive a response
as soon as possible, and a fix will be released before the details are made public.

## Data handling

ActivityFlow is fully offline: it stores data only in `%LOCALAPPDATA%\ActivityFlow` on your computer and makes no
network requests. Only download builds from this repository's
[Releases page](https://github.com/miladdhs/activityflow-persian-time-tracker/releases) and verify the published
SHA-256 checksum.
