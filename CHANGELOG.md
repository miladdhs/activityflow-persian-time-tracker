## [1.0.0] — 2026-10-09

First public release.

### Added
- Dashboard with today / month totals, 7-day chart, project share, recent and frequent activities.
- Activity logging with title autocomplete, similar-title detection, Jalali date picker, duration or start/end time, quantity with unit and notes.
- Activity history with search, filters, sorting, pagination, edit / duplicate / delete and CSV export.
- Projects with colors and statuses (active, paused, completed, archived).
- Reports for month, year or custom ranges grouped by title, project or category, with drill-down and Excel, PDF and CSV export.
- Settings for Persian / Latin digits, Jalali / Gregorian calendar, categories, units and title merging.
- Daily automatic backups, manual backup / restore with integrity checks and JSON export.
- Single-file and folder Windows builds via PyInstaller; CI and automated GitHub releases.
